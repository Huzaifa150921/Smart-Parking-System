# Slot Monitoring Model 🎯🅿️

A **Slot Monitoring Model** that automatically detects **free, reserved, and occupied parking slots** in real-time using **computer vision**.  
This model is a core part of the **Smart Parking System**, helping automate parking management efficiently.

---

## 📌 Features

- Real-time detection of **free, reserved, and occupied slots**  
- Integration with **camera feeds** for live monitoring  
- Slot status updated dynamically on the app dashboard  
- Works with **YOLO-based object detection** for high accuracy  
- Supports **color-coded status**:  
  - Green → Free  
  - Yellow → Reserved  
  - Red → Occupied  

---

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Huzaifa150921/Slot_Monitoring_Model.git
cd Slot_Monitoring_Model
```
# Install Dependencies
pip install --upgrade pip
pip install -r requirements.txt

# Run the Model
python slot_monitoring.py

The model processes camera feeds or test videos and outputs slot occupancy visualization in real-time.

# 🧠 Concepts Used

YOLO Object Detection

Python scripting for automation

Integration with Smart Parking System app for live updates
